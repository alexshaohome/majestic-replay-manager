Majestic Replay Manager

Majestic Replay Manager is a personal Windows desktop application for managing gameplay recordings and uploading them to the owner's YouTube channel.

Features

  • Automatically detect new gameplay recordings.
  • Upload videos privately using the YouTube Data API.
  • Manage uploaded videos and their retention periods.
  • Delete expired private videos uploaded by the application.
  • Clean up old local recording files.

Google Account Access

The application uses Google OAuth 2.0 authorization to access the owner's YouTube channel. Authorization is required to upload, view, and delete videos managed by the application.
