# Privacy Policy

**Last updated:** October 29, 2026

## 1. Overview

Majestic Replay Manager is a personal Windows desktop application that automates the management of gameplay recordings on the owner's YouTube channel.

## 2. Information Accessed

The application uses Google OAuth 2.0 to access the authorized user's YouTube account.

It accesses video identifiers, metadata, privacy status, and information necessary to upload and manage videos.

## 3. How Information Is Used

YouTube account access is used exclusively to:

- Upload gameplay recordings as private videos.
- Check the privacy status of uploaded videos.
- Delete expired private videos previously uploaded by this application.
- Display upload history and video information.

The application does not delete YouTube videos that were not uploaded and registered by Majestic Replay Manager.

## 4. Data Storage

Application settings, OAuth credentials, upload history, and video identifiers are stored locally on the user's computer.

OAuth credentials are protected using Windows security mechanisms.

## 5. Data Sharing

The application does not sell or share personal information with third parties.

Video data is transferred to YouTube using Google's official YouTube Data API.

## 6. Data Retention and Deletion

The application supports configurable retention periods for uploaded videos and local recordings.

Expired YouTube videos are deleted only when they were uploaded by this application and remain private.

Public and unlisted videos are not automatically deleted.

Local recording files may be deleted according to user-configured cleanup settings.

## 7. Revoking Access

Users can revoke the application's Google account permissions at:

[Google Account Connections](https://myaccount.google.com/connections)
